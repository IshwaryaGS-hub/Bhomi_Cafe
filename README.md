# Mitti café

A Vite + React café concept inspired by the supplied tea and coffee website references.

Run `npm install`, then `npm run dev`. Production: `npm run build`.

Includes scroll-driven origin storytelling, animated SVG pouring, steam and droplets, automatic journey playback, tea/coffee menu switching, cup detail dialogs, responsive navigation, and reduced-motion styling. This version uses animated photography and SVG rather than filmed video or a 3D cinematic sequence. Menu prices and the Mitti name are illustrative. No checkout or backend is required for this presentation site.
